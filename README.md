> **These plugins run code on your machine with your access.** They include scripts, hooks or local servers.
> Every file was scanned and reviewed by FindAgent, and each plugin's source is shown on its FindAgent page —
> read it before you install. FindAgent never runs these for you.

This repository is a **generated mirror** of the FindAgent catalog's local tier. Do not open pull requests
against it — changes are overwritten on the next sync.

## Add the marketplace

| Client | Command |
|---|---|
| Claude Code | `/plugin marketplace add team886/findagent-plugins-local` |
| GitHub Copilot CLI | `copilot plugin marketplace add team886/findagent-plugins-local` |
| VS Code | add `team886/findagent-plugins-local` to `chat.plugins.marketplaces` |
| Codex | add the marketplace `team886/findagent-plugins-local` |

Most agents do not need this tier. The main marketplace is
[team886/findagent-plugins](https://github.com/team886/findagent-plugins).
